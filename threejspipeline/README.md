# Three Js Pipeline:

## A simulator for customizing different data operation flows.  

### Project Description

This npm vite app aims to serve as a vanilla template in future and other closed-source projects. 

The user can set the number of units to send through the pipeline. The Three.js scene deploys softbody physics to render a "hose" pipeline with a *locally expanding bulge*.

Future upgrades will feature a Python CLI rich with descriptive flags to control this app live. For now, the parameters are set within the app while future patches will introduce a more formal parameters.json file.
